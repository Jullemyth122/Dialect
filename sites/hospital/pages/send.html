Send results to {{otherName}}

A patient is referred from {{name}} to {{otherName}}. Their results go out as one message, each line carrying your lab's code and, if you approved one, the worldwide LOINC code.

How does this work in a real hospital?

Nobody types this by hand in a real hospital. The interface engine (the software between the lab system and other hospitals) builds an HL7 result message automatically and adds the LOINC code from your approved matches.

Here you fill it in yourself, so you can see exactly what travels between hospitals. Only this file goes to {{otherName}}: never your test list, your approvals or any AI key.

Each result line

  • Approved code: arrives as GLU-F + 14771-0, so {{otherName}} can line it up.
  • Not approved yet: arrives as GLU-F only. {{otherName}} puts it under "do not compare".
