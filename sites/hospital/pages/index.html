About the data
How it works

From a local code to a safe comparison.

  1. Keep only the test

    Only the code, name, unit and normal range are read. Never the result or the patient.

  2. Shortlist in plain code

    Rules, not AI, find the LOINC codes that could fit, and check each code's unit.

  3. The AI picks or asks

    It chooses from the shortlist, or says "please check" with a reason.

  4. A person approves

    Nothing is saved until the analyst confirms. The hospital remembers it, here only.

The open agentic web

Hospitals share the skill, not their data.

This site publishes its mapping assistant as a public agent network. Another hospital's site can load it in its own browser, with the visitor's consent, and adapt it to its own codes.

What exists already, and what's new

AI lab mapping isn't new. Sharing it this way is.

Tools such as LabBridge, LARA and Regenstrief's RELMA already match local lab names to LOINC. Dialect's addition is how the skill travels: published on the open agentic web, adapted at each hospital without either one sending its data to the other, and tuned to ask instead of guess.

Sources for every tool named here are listed in the project's facts file on GitHub.
