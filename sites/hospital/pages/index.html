How does it work?

A lab may write fasting blood sugar as GLU-F 5.6 mmol/L, while another writes Glucose, Fasting 101 mg/dL. Dialect matches each name to its worldwide code (LOINC), so results can be compared and explained.

Plain rules shortlist the possible codes, the AI picks one or says "please check", and a person approves it. A confident wrong match costs far more than asking, so it asks when unsure.

For developers and judges

This is an open agentic website. Its agent network is public at {{networkName}}.network.json (manifest). Another hospital's site can run it in its own browser, with the visitor's consent. They share the skill, never their data.

AI lab mapping already exists (LabBridge, LARA, RELMA). What's new is sharing the skill between hospitals this way and tuning it to ask instead of guess.
