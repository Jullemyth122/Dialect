About Dialect

A demo for the Open Agentic Web Challenge. Real lab standards, fictional hospitals, so anyone can try it safely.

RealLab test codes (LOINC), message formats (HL7) and explanations (MedlinePlus), all cited.
Made up{{name}}, {{otherName}}, every patient and every result.
NeverMedical advice. Dialect explains what a test is, never what a result means for you.
What is sent where

Only a test's local code, name, unit and normal range (HL7 fields OBX-3, OBX-6, OBX-7) are sent, and only to the AI model the site uses. Result values and patient fields are never read into the request. The patient view also sends the matched LOINC code (a public code) to MedlinePlus to fetch its explanation. Nothing from B (lab list, alias table, key) is sent to Hospital A.

When the lab assistant is used, chat messages also go to the chosen AI provider. Approved matches are stored in this browser only.

Safety rules we never break
  • No interpretation, diagnosis or treatment advice anywhere.
  • High and low marks are only the lab's own.
  • Patient explanations come only from MedlinePlus, never from AI.
  • Unit conversions use only cited factors.
  • A person approves every code match.
