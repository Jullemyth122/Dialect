About and data

What's real, what's not, and what goes where.

Dialect is an entry in the Open Agentic Web Challenge. It is a demonstration, built with real standards and fictional hospitals, so anyone can try it safely.

Real

Standards and codes

LOINC codes and names, HL7 v2 message fields, UCUM units, and MedlinePlus explanations, each from a cited public source.

Based on real patterns

Hospital dialects

Each hospital's test list uses naming habits seen in real labs: short codes, abbreviations such as SGPT, and SI or conventional units.

Fictional

Hospitals and patients

{{name}} and {{otherName}} don't exist. Patients are labelled SYN-000123 and similar. Every value is made up.

What is sent where

Only a test's local code, name, unit and normal range (HL7 fields OBX-3, OBX-6, OBX-7) are sent, and only to the AI model the site uses. Result values and patient fields are never read into the request. The patient view also sends the matched LOINC code (a public code) to MedlinePlus to fetch its explanation. Nothing from B (lab list, alias table, key) is sent to Hospital A.

When you use the assistant, your chat messages also go to the AI provider you choose. Approved matches are stored in this browser's storage for this site only.

Rules Dialect never breaks

  • Never medical advice: no interpretation, diagnosis or treatment suggestions anywhere.
  • Flags are shown only as the lab sent them. Dialect never computes its own.
  • Patient explanations come only from MedlinePlus, never from an AI model.
  • Unit conversions use only cited factors; anything else is shown as reported.
  • A person approves every match before it is saved.

For agents and other sites

This site's agent network is public at {{networkName}}.network.json, described by agent-manifest.json. Its network address is {{networkUrl}}. Another agentic website can run it in its own visitor's browser after that visitor agrees; it gets none of this site's page tools or data.
